Text-based Minecraft project written in Python.

## Features

- inventory system
- crafting system
- tools, blocks and food
- health and hunger stats
- saving and loading with JSON
- custom exceptions

## Project structure

```
text
main.py
items.py
inventory.py
crafting.py
stats.py
persistency.py
exceptions.py
recipes.json
user.json
```
### Run

git clone https://github.com/Wolverine021/TextMC.git
cd TextMC
python3 main.py
